# Запись на приём (1С:Предприятие 8.3)

Конфигурация сервиса записи на приём: справочники, документы «Запись на приём» и «Оплата услуг», регистр накопления «Оказанные услуги», АРМ «Администратор» (планировщик), отчёт «Оказанные услуги за период» (СКД).

## Состав репозитория
- `src/` — исходники конфигурации (выгрузка из Конфигуратора в файлы)
- `db/ZapisNaPriem.dt` — выгрузка информационной базы с демонстрационными данными
- `docs/` — описание бизнес-процессов (IDEF0, IDEF3, EPC)

## Как запустить
1. Создать пустую информационную базу в 1С:Предприятие 8.3.
2. Конфигуратор → Администрирование → Загрузить информационную базу → выбрать `db/ZapisNaPriem.dt`.
